Combining Large Language Models & Knowledge Graphs for Energetic Renovation Suggestions
---
Repository for the short paper 'Combining Large Language Models & Knowledge Graphs for Energetic Renovation Suggestions', submitted to the International Workshop Scaling Knowledge Graphs for Industry (SKGi) 2026.

The code discussed in the short paper is in the folder 'STEP 1'. The other steps are provided as they can be useful for future research.

# STEPS
1. **zero-shot -> zero-shot judge (short paper)**
2. zero-shot with suggestion list -> zero-shot judge
3. zero-shot CoT with suggestion list -> zero-shot CoT judge
4. few-shot -> few-shot judge
5. few-shot with suggestion list -> few-shot judge
6. few-shot CoT with suggestion list -> few-shot CoT judge
7. zero-shot CoT with suggestion list and retrieval -> zero-shot CoT judge
8. few-shot CoT with suggestion list and retrieval -> few-shot CoT judge
9. zero-shot CoT with suggestion list -> zero-shot retrieval -> zero-shot CoT judge
10. few-shot CoT with suggestion list -> few-shot retrieval -> few-shot CoT judge
